# 单一当前规则与读取路由

适用0.5.0-current.1。唯一验收依据见[当前标准](current-standard-policy.md)，不再选择历史版本、批次豁免或人工等级。未分级规范/L0及明确延续的项目G01/G03、正式单seed2h/多seed8h、平台官方源/bnpm要求统一必需，其余L1/L2完整记录为建议；全部90编号继续逐项审。这些是既有要求延续，不是本轮新增硬门。

| 何时读取 | 规范 |
|---|---|
| 每次 | [当前标准](current-standard-policy.md)、[自动协议](automation-review.md)、[21项](implementation-policy.md)、[G三项](research-quality.md) |
| 交付与工程 | [提交格式](submission-format.md)、[Harbor](harbor-harness.md)、[合同](delivery-contract-review.md)、[工程六组](engineering-review.md)、[provider](provider-policy.md) |
| 证据与轨迹 | [Baseline](baseline-quality.md)、[运行证据](runtime-integrity.md)、[内部底稿](implementation-report.md)、[CS03–05](current-standard-checks.md) |
| 完整增量 | [A/B合并](unified-increment.md)、[原A正文](increment/original/SKILL.md)、[原A案例](increment/original/EVAL_CASES.md)、[平台诊断](increment/platform-audit.md) |
| 定稿 | [90项映射](standard-coverage.md)、[统一输出](unified-report.md) |

原A两文件字节保留并独立读，其排除范围只限定A，不能取消其他当前必需实错。平台原因族是排查当前真实故障的线索；明确延续平台要求按当前标准统一执行，旧批统计不作门。历史比较、豁免、迁移说明不在活动读取路由；归档文件不具有更高优先级。

provider及source/runtime描述材料事实，unknown不单独拦静态；真实能力由平台核验。mode/cohort/target-level等旧参数若由CLI保留兼容，不改变单一当前标准。上下文以调用方固定参数和真实模板为准，Agent不得为结果改版本或冒称已完成动态验证。

所有正式协议声明seed及全部已交轨迹/会话读完，不以摘要取代；完整检查不等于恢复固定两模型/10h/八字段等旧必交项。无分暂停口径、50G证据边界、NOP取消与最终二值判断统一按当前标准。
