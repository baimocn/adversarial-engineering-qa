# 适用范围与检查顺序

1. **清点完整当前包和已有证据。**定位题面、实际接口、Baseline/Reference、正式结果、双轨、专家分析及best_method，不能只检查文件存在。
2. **完成三门控。**读实际方法空间、Baseline合理性与公平性、Reference提升；用已有正式原值逐seed配对复算均值、样本标准差、改善及归一化。
3. **完成每一项QA和Harbor检查。**QA01–QA21、H01–H06都记录内容和证据，不整体删除或一笔豁免。
4. **阅读两轨实际内容并比较研究条件。**说明方法演进、失败与选择、最终结果及与summary/best的一致性；核两次实际Prompt/任务、Dev、失败反馈和IPC/只读等限制。两轨独立不等于同条件可比；已有相关sessions一并审，不要求新交sessions。
5. **逐问题应用豁免。**同项有多个原因分别处理；新字段缺口可免，另一题轨迹、真实科学门失败或当前交付缺陷仍保留。
6. **回读完整报告。**报告和通过说明都有本题实质摘要、每项原判与具体豁免；未审完不能凭格式通过给总PASS，不以耗时凑分钟数。

以下是具体历史或平台原因的处理方式，不是免读已有材料。先完成对应项目的实质审阅，再保留原判并记录豁免；同项其他真实问题继续生效。
