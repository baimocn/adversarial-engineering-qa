# Baseline 合理性检查

总评：**不合理（指当前正式对照的预算有效性；Baseline 自身实现及训练在已提供材料范围内合理）**。

角色：Starter 与正式 Baseline 都是 `workspace/harbor_task/environment/starter/models/BaselineFormer.py` 的三尺度卷积 + Transformer，d64/ff128/e2、76,529 参数。Reference 是 `workspace/reference/ref_code/models/MedMamba.py` 的多分支差分/频域 SSM 与空间图 Mamba，d256/ff512/e4、15,955,713 参数。模型容量与架构属于允许变量，差异本身不判不公平。主评分 B 仍为旧正式三 seed 均值 0.644488；最新正式汇总改用 0.6447076768569452，映射尚未统一（QA02/QA21）。未提供适用的独立 sanity 对照，不编造其分数，也不因没有它自动判失败。
